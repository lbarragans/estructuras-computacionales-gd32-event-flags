# Regla global de lenguajes

La barra **Languages** de GitHub debe representar los lenguajes realmente usados
por las implementaciones educativas.

- C cuenta cuando forma parte real de una solucion.
- Assembly cuenta cuando forma parte real de una solucion.
- FreeRTOS es tecnologia/RTOS, no lenguaje.
- PowerShell, CMake, JSON, VS Code y Markdown son auxiliares.
- No se oculta un lenguaje real para fabricar un porcentaje.
