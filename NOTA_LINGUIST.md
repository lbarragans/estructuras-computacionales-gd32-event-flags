# GitHub Linguist en este repositorio

Las variantes utilizan C y una implementacion emplea instrucciones atomicas
RISC-V en Assembly.

Por ello GitHub puede mostrar:

```text
C          xx.x %
Assembly   yy.y %
```

Los porcentajes exactos los calcula GitHub.

PowerShell, CMake, JSON, configuracion de VS Code y Markdown no forman parte de
la implementacion del mecanismo de eventos y no deben alterar la barra.
