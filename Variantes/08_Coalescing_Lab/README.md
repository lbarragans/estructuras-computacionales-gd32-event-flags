# 08 - Laboratorio de coalescencia

## Lenguaje

C.

## Experimento

Publicar tres veces el mismo bit antes de reclamarlo:

```text
publish
publish
publish
claim
```

produce:

```text
3 llamadas de publicacion
1 observacion del bit
```

## Objetivo

Distinguir:

```text
evento pendiente
```

de:

```text
numero de ocurrencias
```

## Estado

**Fuente lista.**
